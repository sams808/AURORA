AURORA on macOS: the first launch
==================================

AURORA needs macOS @MIN_MACOS@ or later. Use the arm64 disk image on a Mac with Apple silicon (M1 and later) and the
x86_64 disk image on an Intel Mac.

The simplest way, with no security message at all: open Terminal and run this one line, which installs AURORA
from its GitHub page (after checking it) and opens it:
  curl -fsSL https://raw.githubusercontent.com/sams808/AURORA/main/packaging/install_mac.sh | bash

From this disk image instead:

1. Drag AURORA into the Applications folder (the shortcut next to it in this window).

2. Open AURORA from Applications. AURORA is free software that is not notarised by Apple, so the first time
   macOS stops it with a message such as "Apple could not verify AURORA is free of malware". Click Done
   (not Move to Trash). Then open System Settings > Privacy & Security, scroll down to the Security section,
   click "Open Anyway" next to the message about AURORA, and confirm with your password or Touch ID.
   This is needed once; afterwards AURORA opens normally.

   Alternative (Terminal), the same effect:
     xattr -dr com.apple.quarantine /Applications/AURORA.app

3. If macOS says AURORA "is damaged and can't be opened", the download was altered on the way; download the
   disk image again and compare it with SHA256SUMS.txt of the release (shasum -a 256 <file>).

Help > Manual inside AURORA explains everything else. Settings live in ~/Library/Preferences, the log file in
~/Library/Logs/AURORA (Help > Report a problem… > Open the log folder). AURORA never writes into the raw/ folder
of a beamtime.
LICENSE, CREDITS.md and THIRD_PARTY_LICENSES.txt next to this note hold the licences.
